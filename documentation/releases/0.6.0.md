# Homi 0.6.0 — Household Tasks, People map focus and shell polish

Date: 2026-09-10
Version: `0.6.0+6`

## Tasks

- Moved the explanatory Task copy behind a compact **How it works** action instead of leaving a large disclaimer in the page flow.
- **No due time** replaces the older “Leave open” wording.
- Completed Tasks remain visible under **Recently completed** for 48 hours, showing who completed them and when.
- Local completed Tasks are purged from persisted state after the retention window when Homi loads/prunes them.
- Shared completed Tasks are hidden after the same retention window and are best-effort deleted from Firestore by an authorised household client on sync.
- Tasks assigned to **Me** remain private/local.
- Tasks assigned to another household person, or to **Anyone at home**, can be shared to the creator's chosen Household people. Every authorised household viewer can see the assignee, due time and completion attribution.
- Location-only friends remain excluded from household Task collaboration.

## Routines

- Added **Bi-weekly** recurrence using one selected weekday on a 14-day cadence.
- Added launch-facing **60+ min** duration selection.
- Bi-weekly scheduling is persisted and covered by deterministic tests.
- Existing reversible recurring completion remains: complete → undo → complete again restores the same scheduled occurrence rather than skipping ahead twice.

## Overview

- Overview **Quick add** is now a destination launcher rather than creating another ambiguous reminder type.
- Quick add offers Task, Routine, Supply and Home and routes into the appropriate primary area.
- Existing legacy Quick Add reminder strings remain readable/removable for migration safety, but Overview no longer creates new vague reminder records.
- Overview now includes local open Tasks in attention counts alongside due Routines, Supplies and Home service attention.

## People / map

- People keeps its page state alive and seeds itself from the app-level cached/latest location and current live-stream state before async refresh work begins.
- This is intended to prevent the brief “live sharing is off / no location yet” flash seen after swiping away and back.
- Added an **Open map** action from the People map.
- Added a dedicated full-screen interactive Google Map with normal pan/zoom behavior.
- Added person focus chips on the embedded and full-screen maps. Selecting a person centres the map on their profile-photo marker.
- Trusted-person cards can focus that person's map location directly.
- Location details retain individual address/coordinate copy icons, **Copy all**, Google Maps, battery, accuracy and freshness.
- Trusted-person sync errors no longer assume the internet is the problem. Last successfully received location state is kept, user-facing copy distinguishes secure-sync/unavailable conditions, and a **Retry** action rebinds the private connection/preference streams.
- Removed the now-unnecessary direct `firebase_core` import from the People surface.

## Home

- Utility units are now controlled Homi choices instead of free-form text.
- Electricity choices: `kWh`, `Wh`, `MWh`, `units`.
- Water choices: `kL`, `L`, `m³`, `units`.
- Existing Homi date/time controls remain for readings, service dates, warranties and maintenance history.

## Navigation

- Replaced the hand-shaped active mound with a geometric union of the rounded navbar body and a true circular halo.
- The white halo is therefore genuinely circular around the active control at Overview, Tasks, Home, Supplies and People.
- Edge tabs no longer depend on custom cubic mound points that created the pointed corner visible in physical-device screenshots.
- Home remains centred and still uses the exact approved Homi mark.

## Security / cloud changes

- `sharedTasks/{taskId}.memberUids` may now contain the creator plus the creator's selected Household viewers instead of only creator + assignee.
- A specific non-self assignee still requires an accepted connection and the creator's private Household preference.
- A task assigned to the creator does not enter the shared collection.
- Shared Tasks do not grant access to Home, Supplies, Routines or location.
- Location authorization rules remain owner-controlled and independent from Household status.

## Compatibility

- No Firebase project, package name, Maps key, signing identity or permanent project identifier changed.
- Existing local Tasks remain readable.
- Existing recurring Routine JSON remains readable; bi-weekly is additive.
- Existing utility readings keep their stored unit even if it is not one of the new editor choices.
- Existing legacy Overview Quick Add reminders remain removable.
