# Homi 0.13.2 (Build 20)

## Scope

Focused follow-up to Build 19 based on device acceptance testing.

### Notifications
- Removes the unrequested remote-notification readiness card from the user-facing Notifications page.
- Keeps notification transport diagnostics internal.
- Validates the current FCM registration token before the backend stores it as a usable device.
- If FCM reports that the token is invalid or unregistered, Homi deletes the stale client token, requests a fresh token once, and retries registration.
- Developer self-notification history no longer reports a direct send as successful when zero devices received it.
- Push delivery failures now preserve the FCM error code in backend logs/campaign state for diagnosis.

### Profile
- Shows the current server-authoritative Homi plan on the profile identity card.
- Expired paid records are shown as Homi Free rather than presented as an active paid plan.

### Billing
- No pricing or Play product identifiers changed in this pass.
- Google Play license-test renewal compression remains test-only behavior.
